03Java-Klassendiagramm (Simulationskern)

classDiagram
    class WarehouseSimulation {
        -EventQueue eventQueue
        -SimClock clock
        -List~Generator~ generators
        +run()
        -process(SimEvent evt)
        -generateRandomEvent()
    }
    class EventQueue {
        -PriorityQueue~SimEvent~ queue
        +add(SimEvent evt)
        +poll() SimEvent
        +isEmpty() boolean
    }
    class SimEvent {
        +EventType type
        +LocalDateTime scheduledTime
        +Map data
    }
    class EventType {
        <>
        WARENEINGANG
        AUFTRAG_EINGEGANGEN
        KOMMISSIONIERUNG_FERTIG
        WARENAUSGANG
        INVENTURDIFFERENZ
    }
    class SimClock {
        -LocalDateTime currentTime
        -double speedFactor
        +now() LocalDateTime
        +advanceTo(LocalDateTime t)
    }
    class OrderGenerator {
        -DemandDistribution distribution
        +generateNextOrder() SimEvent
    }
    class InboundGenerator {
        +generateInbound() SimEvent
    }
    class DemandDistribution {
        +samplePoisson(double lambda) int
    }
    class BestandsService {
        -BestandRepository repo
        +erhoehen(int artikelId, int platzId, int menge)
        +verringern(int artikelId, int platzId, int menge)
        +pruefeMindestbestand(int artikelId) boolean
    }
    class KommissionierungsService {
        -AuftragRepository auftragRepo
        -BestandsService bestandsService
        +starteKommissionierung(int auftragId)
        +schliesseAb(int auftragId)
    }
    class EventLogService {
        -EventLogRepository repo
        +log(SimEvent evt)
    }
    class ArtikelRepository
    class BestandRepository
    class BewegungRepository
    class AuftragRepository
    class EventLogRepository

    WarehouseSimulation --> EventQueue
    WarehouseSimulation --> SimClock
    WarehouseSimulation --> OrderGenerator
    WarehouseSimulation --> InboundGenerator
    EventQueue --> SimEvent
    SimEvent --> EventType
    OrderGenerator --> DemandDistribution
    WarehouseSimulation --> BestandsService
    WarehouseSimulation --> KommissionierungsService
    WarehouseSimulation --> EventLogService
    BestandsService --> BestandRepository
    KommissionierungsService --> AuftragRepository
    KommissionierungsService --> BestandsService
    EventLogService --> EventLogRepository

04Ablauf eines Auftrags (Sequenzdiagramm)

sequenceDiagram
    participant Sim as WarehouseSimulation
    participant OG as OrderGenerator
    participant KS as KommissionierungsService
    participant BS as BestandsService
    participant DB as PostgreSQL
    participant EL as EventLogService

    Sim->>OG: generateNextOrder()
    OG-->>Sim: SimEvent(AUFTRAG_EINGEGANGEN)
    Sim->>DB: INSERT INTO auftrag
    Sim->>EL: log(AUFTRAG_EINGEGANGEN)
    Sim->>Sim: schedule(KOMMISSIONIERUNG_FERTIG, +5min)

    Note over Sim: ... Zeit vergeht ...

    Sim->>KS: starteKommissionierung(auftragId)
    KS->>BS: verringern(artikelId, menge)
    BS->>DB: UPDATE bestand
    BS->>DB: INSERT INTO bewegung (WARENAUSGANG)
    KS->>DB: UPDATE auftrag SET status='abgeschlossen'
    Sim->>EL: log(KOMMISSIONIERUNG_FERTIG)

06Docker-Compose-Grundgerüst (Säule 1 + 3 verbinden)

version: "3.9"
services:
  postgres:
    image: postgres:16
    environment:
      POSTGRES_DB: lagersim
      POSTGRES_USER: lager
      POSTGRES_PASSWORD: changeme
    ports:
      - "5432:5432"
    volumes:
      - ./database/init:/docker-entrypoint-initdb.d
      - pgdata:/var/lib/postgresql/data

  grafana:
    image: grafana/grafana:latest
    ports:
      - "3000:3000"
    volumes:
      - ./dashboard/grafana/provisioning:/etc/grafana/provisioning
      - ./dashboard/grafana/dashboards-json:/var/lib/grafana/dashboards
    depends_on:
      - postgres

volumes:
  pgdata:

08Paket-Verantwortlichkeiten (Java)

PaketVerantwortlichkeit
coreEvent-Queue, Zeitsteuerung, Hauptschleife der Simulation
generatorErzeugt zufällige, aber realistische Ereignisse
domainReine Datenklassen (entsprechen DB-Tabellen)
repositoryDatenbankzugriff (JDBC/JPA) pro Tabelle

configVerbindungsdaten, Properties

09Reihenfolge zum Aufbau der 3 Säulen

Säule 1 — Datenbank
  1. database/init/01_schema.sql schreiben
  2. Mit Docker starten
  3. Mit DBeaver oder IntelliJ Database Tool prüfen
Säule 2 — Java
  1. domain implementieren
  2. repository implementieren
  3. service implementieren
  4. core (Event-Queue + Clock) implementieren
  5. generator implementieren
  6. Main.java zum Starten schreiben
Säule 3 — Grafana
  1. Docker-Compose erweitern
  2. Datasource provisionieren
  3. Erste Panels manuell bauen
  4. Als JSON exportieren nach dashboards-json/
